# Манифесты основного установщика

Эти файлы находятся в репозитории, чтобы `install.sh` мог применять их без
отдельных запросов к `raw.githubusercontent.com` и GitHub release assets.
Образы контейнеров Kubernetes загружает из реестров отдельно.

| Компонент | Версия |
| --- | --- |
| Multus | v4.3.0 |
| KubeVirt | v1.9.0 |
| CDI | v1.65.0 |
| External snapshotter | v6.3.3 |

`sources.json` содержит исходные официальные адреса, версии и SHA-256.
Перед применением установщик проверяет файлы по `SHA256SUMS`.
Копии YAML сохранены без изменений. При настройке Multus установщик
подставляет пути K3s и закреплённый digest образа `v4.3.0-thick`.

При обновлении компонента скачайте все его связанные манифесты из одного
официального релиза, проверьте опубликованные контрольные суммы, обновите
`sources.json` и `SHA256SUMS`. Проверьте YAML и конфигурацию Multus через
`backend/tests/test_install_network.py`.
