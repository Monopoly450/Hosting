# Руководство по обновлению сервера хостинга в университете

В этом документе описаны изменения, внесённые за сегодня, и приведена подробная инструкция по обновлению вашего основного сервера в университете.

---

## 🛠 Что было сделано сегодня:

1. **📱 Исправлен перенос текста на телефонах**:
   * Текст под шкалами ресурсов (CPU, RAM, Диск) больше не накладывается друг на друга на узких экранах, а выстраивается в удобную вертикальную колонку.

2. **📊 Реальные лимиты ресурсов**:
   * Показатель **«Доступно для новых ВМ»** теперь рассчитывается по физическим формулам (с учетом реального свободного места на диске и свободной оперативной памяти на хосте), предотвращая переполнение памяти (OOM) и сбои при запуске ВМ.

3. **⚙️ Управление пулом LVM из веб-интерфейса**:
   * Внедрена кнопка-шестерёнка и **выезжающая боковая панель (Slide-over)** для управления размером хранилища LVM (`vg-aegis`).
   * Реализовано как расширение пула дисков, так и безопасное уменьшение (LVM автоматически заблокирует сжатие, если занятые сектора ВМ выходят за рамки нового размера).

4. **🐳 Проброс LVM и утилит в Docker**:
   * В `docker-compose.yml` проброшены пути `/var/lib/aegis` и `/run/lvm` для бэкенда и воркера.
   * В `Dockerfile` бэкенда добавлен пакет `lvm2`, чтобы команды `pvresize` выполнялись прямо из контейнера.

5. **🔄 Автоматическое восстановление дисков и сети при перезагрузке**:
   * Скрипт `scripts/setup-autostart.sh` теперь создаёт отказоустойчивую системную службу, которая автоматически монтирует петлевой диск, поднимает Volume Group LVM и восстанавливает правила NAT-маршрутизации (iptables) при перезапуске сервера.

## 📥 Инструкция по обновлению сервера в университете:

Выполните эти шаги по очереди в терминале вашего сервера в университете:

### Шаг 1. Перейдите в рабочую папку и загрузите обновления из GitHub
```bash
cd ~/Hosting
git pull
```

### Шаг 2. Примените обновлённые системные службы автозапуска и LVM
Это обновит службу `/etc/systemd/system/aegis-lvm-loop.service` на хосте, чтобы диски и сеть восстанавливались автоматически:
```bash
sudo bash ./scripts/setup-autostart.sh
sudo bash ./scripts/install-openebs-lvm.sh
```

### Шаг 3. Пересоберите и запустите контейнеры Docker
Флаг `--build` обязателен, чтобы Docker установил пакет `lvm2` внутрь образа бэкенда и применил новые монтирования томов:
```bash
docker compose up -d --build
```

## 🔍 Проверка успешности установки:

1. **Проверьте статус контейнеров**:
   Убедитесь, что все службы запущены успешно (`Up` или `healthy`):
   ```bash
   docker compose ps
   ```

2. **Проверьте доступность LVM из контейнера бэкенда**:
   Зайдите в контейнер бэкенда и проверьте, видит ли он дисковый пул LVM:
   ```bash
   docker compose exec backend pvdisplay
   ```
   *(Команда должна вывести информацию о физическом томе `/dev/loop0` или аналогичном)*.

3. **Проверьте интерфейс**:
   Откройте веб-панель администратора в браузере, перейдите к дискам, нажмите на шестерёнку настроек LVM справа и проверьте работу боковой панели.
